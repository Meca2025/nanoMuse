Starting the phone…手机启动中…

A phone in your browser, with a nanoMuse of your own on it. 浏览器里的一台手机，上面装着一个属于你的 nanoMuse。

The phone is MobileGym, as on its own site — WeChat, Alipay, 12306 and two dozen more apps re-created so an agent can use them, with Back, Home and Recents beside it and the State Builder to its right. The Muse on it is real: a private nanoMuse started for you on our server, for a while. Tap a line below, or type anything into its chat. 手机是 MobileGym，和它官网上的一样——微信、支付宝、12306 等二十多个常用应用为了让智能体能上手操作而重做了一遍，旁边是返回 / 主页 / 最近任务三个键，右边是它的 State Builder。上面的 Muse 是真的：我们在服务器上为你临时启动了一个专属的 nanoMuse。点下面任意一条试试，或者直接在它的对话框里输入任何话。

A new look换个形象

Describe it and the Muse draws itself — four to pick from, then its poses, then it moves.说一句，它就把自己画出来：四张候选，选一张，再补齐表情，然后动起来。

Let it use the phone让它操作这台手机

It reads the screen and taps, types and swipes in the apps here — a capsule at the top of the phone shows each step, with Stop — and asks before it sends, pays or deletes.它看着屏幕，在这些应用里点、输、滑——手机顶部的胶囊会显示每一步，随时可以停止；发消息、付款、删除之前会先问你。

Remember, remind记住、提醒

What you tell it stays with it; a reminder shows up in the phone's notification shade.告诉它的事它会记住；到点的提醒会出现在手机的通知栏里。

A tap puts the line in the chat on the phone; you send it. Anything else you want to try, type it there. The State Builder beside the phone changes what is on it — a new WeChat message, the time, the battery, a train order — the way MobileGym's own page does. 点一下，这句话就填进手机里的对话框，由你来发送。想试别的，直接在那里输入就行。手机旁的 State Builder 可以改手机里的东西——塞一条微信消息、改时间、改电量、加一张火车票订单——和 MobileGym 官网上一样。

How this runs这是怎么跑起来的

The phone is MobileGym: Android-style apps re-implemented for the browser, with task stacks, intents and a notification shade — no emulator, no APK. nanoMuse's app on it is a thin client. The agent itself does not fit inside a simulated phone (on a real one, the whole runtime lives in the APK), so each visitor gets a container of their own on our server for a while, with a model budget; the phone's screen is one of the things that Muse can see and touch — it sees the same picture and element list the Android app sends, and shows the same capsule while it works. When the time is up, the container and everything in it is gone. 这台手机是 MobileGym：把安卓风格的应用在浏览器里重做了一遍，有任务栈、Intent 和通知栏——没有模拟器，也不装 APK。手机里的 nanoMuse 是一个很薄的客户端。智能体本身塞不进一台模拟手机（真机上，整个运行时都在 APK 里），所以每位访客会在我们的服务器上得到一个专属容器，有时限、有模型额度；这台手机的屏幕是那个 Muse 能看能点的东西之一——它看到的截图和元素列表与安卓 App 发的一样，干活时显示的也是同一个胶囊。时间到了，容器和里面的一切一起消失。

Want one that stays? Install nanoMuse on your phone or computer — the same agent, yours for good. 想要一个一直在的？把 nanoMuse 装到你的手机或电脑上——同一个智能体，永远是你的。
